# ミニ四駆ステーション・工房ひなゆめ

ミニ四駆のレース情報とレギュレーションを掲載する静的サイトです。

## ページ構成

- ホーム
- 🏁レース（準備中）
- レギュレーション
  - 懐古レギュ：2023年度レギュレーション本文 ＋ 使用可能パーツ29点
  - アニマルドライバー（準備中）

## 更新のしかた

**本文もパーツ一覧も、`content/` のテキストファイルを直すだけです。**

| 直したいもの | 開くファイル |
|---|---|
| 懐古レギュの条文 | `content/kaiko.md` |
| レースの案内 | `content/race.md` |
| アニマルドライバーの案内 | `content/animal.md` |
| 使用可能パーツの一覧 | `content/parts.tsv` |
| 色・レイアウト | `docs/style.css` |

編集したら、リポジトリのフォルダで次を実行します（Python 3、追加ライブラリ不要）。

```
py build_site.py
```

`docs/` のHTMLが作り直されるので、そのままコミットして push すれば公開されます。

### content/*.md の書き方

先頭が見出し情報、`---` から下が本文です。

```
title: 懐古レギュ          ページの見出し
eyebrow: NOSTALGIC CLASS   小さな英字ラベル
roundel: 懐古              右上の丸いマーク
badge: 2023年度            見出し下のタグ（不要なら行ごと消す）
---
## 見出し

- 箇条書き
- **太字** はこう書く

> ※この形で書くと、黄色い注意ボックスになります。

{{parts}}    ← 使用可能パーツ一覧（画像＋検索）が入る場所
```

使えるのは `##`／`###` 見出し、`- ` 箇条書き、`> ` 注意ボックス、`**太字**`、空行区切りの段落だけです。

### content/parts.tsv の書き方

**タブ区切り**で1行1パーツ。`#` で始まる行は無視されます。

```
ファイル名	品番	商品名	カテゴリ
p01_r02_c01	15111	丸穴ボールベアリング 4個セット	ベアリング・ローラー
```

「ファイル名」は `docs/assets/parts/` に置いた画像の名前（拡張子 `.png` は書かない）です。
パーツを増やすときは、画像を `docs/assets/parts/` に入れてから、この行を足します。
並び順＝ページの表示順。件数（「全29点」など）は自動で数えます。

## GitHub Pagesでの公開

リポジトリの **Settings → Pages → Build and deployment** で以下を選択します。

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/docs**

公開URL： https://HNHN-g1t.github.io/MINI4-HINAYUME/

生成済みHTMLもリポジトリで管理するため、GitHub Pages側でのビルドは不要です。

画像は選定済みの高解像度PNGをそのまま使用しています。カタログの価格・商品情報は当時のものです。
レース日程や追加の参加条件など、未提供の情報は掲載していません。
